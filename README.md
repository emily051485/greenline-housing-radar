# 綠線居住雷達

台北捷運綠線步行 12 分鐘內的新建案、預售屋與潛在都更案研究介面。

網站目前分為兩個共用程式與圖資的頁面：

- `/`：綠線潛力案，保留土地整合、都市更新、建照與預售等不同成熟度。
- `/greater-taipei/`：大台北成熟建案，只收錄已領建照、預售備查、預售中或新成屋階段，且基地已定位的案件。

大台北成熟版採可信資料優先，目前整合既有逐案覆核資料，以及預售屋全面備查制度上路後的內政部資料。備查地址以台北市、新北市官方門牌座標配對，再以官方捷運出口計算最近車站與距離；不限制離捷運距離，但無門牌、只有路口或無法可靠定位者不會以車站中心或行政區中心代替。預設顯示 C 級以上，可切換「全部評等」查看尚未完成建商品牌評級的案件。

## 啟動

```bash
npm install
npm run dev
```

更新臺北市官方主地號定位資料後重新整合：

```bash
npm run data:locations
npm run data:metro
npm run data:integrate
npm run build
```

`npm run data:metro` 會把臺北市捷運工程局的路網 GIS 與政府 ArcGIS 的桃園機場捷運線形轉成網站內建快取；即時 OSM 服務失敗時，主要捷運線仍會顯示。淡海、安坑、三鶯與萬大樹林等路線則由網站載入 OSM 資料補充，並排除已快取路線，避免同一路線畫成兩條。

`data:locations` 會從臺北市 TGEO 地籍圖下載案件名稱所列的第一筆地號 polygon。網站把它標示為「官方主地號宗地」，不把單一宗地誤稱為完整更新基地。

Google Maps 連結只顯示於已確認存在正式建案／建築基地標記，或由建案官網提供 Google Maps 導航點的案件。僅有地籍座標、完整門牌或生活圈推估位置的案件不提供連結，以免把搜尋結果誤認為正式建案地標。

`npm run data:integrate` 會合併臺北市都市更新案件、新北市都市更新核定成果、臺北市建造執照、臺北市實價周報，以及新北市新店區預售屋實價資料。目前整合出 131 筆捷運生活圈候選。預設範圍為 15 分鐘，可切回 12 分鐘。政府來源未附完整基地座標，因此地圖位置和步行時間仍是生活圈初篩，必須再以地籍圖及步行路網逐筆複核。

地圖採 OpenStreetMap，環境設施透過 Overpass API 即時取得並保留 12 小時快取。重大環境設施包含加油站、變電所與電塔、殯葬、公墓、廢棄物、污水、油氣儲槽及工業設施；生活影響設施包含快速道路、鐵路與機廠、機場、醫院、消防隊、宗教活動、夜間娛樂、市場、學校、通訊塔、監獄與軍事設施。依類型採 300 公尺至 3 公里初篩，並不代表設施必然造成負面影響。淹水、液化、活動斷層及坡地風險應另查網站所列政府面狀圖資。

## 資料欄位

每筆標的包含案名、縣市、行政區、捷運站、步行分鐘、地址、建商與研究評等、目前進度、預計完工日、產品類型、坪數、價格、座標與來源。

建照的「起造人」、都更的「申請人／實施者」與實際品牌建商不是同一概念，介面會分開標示。只有確認品牌建商並完成人工評核後才顯示 S／A／B／C；其餘一律為 `— 未評等`。建商評等不是政府評鑑；估計欄位均應加上 `（估）` 或 `待公告`。

建商評等篩選採門檻制：選 A 會顯示 S、A；選 B 會顯示 S、A、B；「未評等」則只顯示尚未完成建商查核的案件。

建商查核會先以「行政區＋地段＋小段＋主地號」比對臺北市都市更新處各行政區的審議表，取得正式實施者，再套用公司級統一評等。C 級表示已確認開發主體，但目前公開可核對的完工履歷或財務資料不足以升評 B，並不等同工程品質不良；都市更新會、建築經理、資產管理公司及仍被遮蔽的起造人維持未評等，避免把非品牌建商誤評為 C。

## 降雨淹水模擬

地圖內建「降雨淹水模擬」圖層，可切換 NCDR／經濟部水利署提供的 6、12、24 小時定量降雨情境。此圖層是特定設計降雨與防洪設施正常運作假設下的潛勢模擬，不是即時淹水預報，也不能作為土地使用或建築安全的單一判定依據。

NCDR 圖層使用短效公開權杖。GitHub Actions 會在每次建置及每天台灣時間 10:17 從官方 WMS 產生十張固定範圍透明 PNG，和網站一起發布。瀏覽器只讀取本站快取，不直接連線權杖 API 或 WMS，因此不受 CORS 與權杖到期影響。若 NCDR 暫時無法回應，該次工作流程會失敗，GitHub Pages 會保留上一個成功版本。

地圖亦提供預設關閉的土壤液化潛勢與活動斷層圖層。液化圖例依官方色碼顯示低（綠）、中（黃）、高（紅）潛勢；活動斷層顯示官方紅線。兩者涵蓋大臺北範圍，透過 GitHub Actions 每日產生本站 PNG 快取。土壤液化潛勢與鄰近活動斷層僅供購屋初篩，不代表個別建築物安全判定。
